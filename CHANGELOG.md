# Changelog

## 0.1.0 (2026-11-12)


### ⚠ BREAKING CHANGES

* **config:** move the [s3] table of omunculus.toml to [settings.s3]; [s3] is now refused as an unknown key.
* **tools:** the report argument of the ending tools is an object, no longer a string.
* **sales-desk:** request_golive and the owner and pm routes are gone. The go-live is the clerk's promote, reviewed by the project manager, then the owner, through an interceptor the project declares. The seller and manager ask the owner with to = owner and the client with to = front-desk. next_stage refuses a sale approved by an agent of the desk.
* **requests:** configs with `request_routes` or `harness_route` are refused; presets, eval configs and overlays use the new keys. Packs and apps that read routes or `destination` are not yet updated.
* **config:** projects relying on the implicit "owner" route must set [policy] harness_route = "owner".
* **sales-desk:** agent sales is front-desk, the sale workflow no longer runs build, and the manager's workflow engagement is required at depth 1.
