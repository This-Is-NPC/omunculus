# Quote file format

One file per client: `quotes/<client-slug>.md`. Labels in English; the
client's own words and the quote text in Portuguese.

```markdown
# Quote: <client name> (<business>)

Status: draft | to be confirmed | sent | accepted, awaiting owner | lost
Updated: YYYY-MM-DD

## Client
- Name and business:
- Contact (as the client gave it):
- Who the site is for:

## Scope asked
- Pages:
- Features:
- Content the client still owes (texts, photos, logo):
- Deadline the client hopes for (not a promise):

## Feasibility
- Dream-team work id:
- Answer: yes | yes with conditions | no
- Conditions or alternative:

## Price
- Base (4 pages): R$ 1.500
- Extra pages: N x R$ 300 = R$ X
- Discount (up to 10%, desk's own): R$ Y
- Total: R$ T

## Waiting for the owner
- Discount above 10%, scope outside the standard, contract, payment, start date:

## Promised to the client
- Only what is written above and confirmed by the dream-team.
```
